# Expected fixture collections

These files are the exact, replayable schema-2 collections for
`examples/metadata-repo`, generated by the canonical collector:

```bash
PYTHONPATH=.agents/skills python -m msdmd.collect \
  --root examples/metadata-repo --repo fixture/metadata-repo \
  --snapshot-identity --strict --json \
  --out examples/metadata-repo-expected/collection-py<VER>.json
```

One file exists per supported interpreter (3.11, 3.12) because the Python
reader records the running grammar version in `convention.version`. The test
gate picks the file matching the current interpreter and replays it with
`--check`; the expected files themselves are inputs, not collection targets,
so they live outside the scanned fixture root.
