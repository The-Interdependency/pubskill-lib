# Expected fixture collections

`collection-normalized.json` is the exact, replayable schema-2 collection for
`examples/metadata-repo` in the **minimal-runtime** environment (no optional
reader dependencies installed). It is generated by the canonical collector:

```bash
PYTHONPATH=.agents/skills python -m msdmd.collect \
  --root examples/metadata-repo --repo fixture/metadata-repo \
  --snapshot-identity --strict --json \
  --out /tmp/fixture-collection.json
```

`collection-normalized-full.json` is the equivalent receipt for the
**full-runtime** environment (Python reader requirements plus
`npm ci`-installed TypeScript). The Docker image replays this receipt after
installing those dependencies.

The only normalization applied to both files is the Python reader's runtime
version label (`"version": "Python 3.x"` becomes
`"version": "Python <normalized>"`), so each committed file replays
byte-for-byte on every supported interpreter in its runtime class. The test
gate regenerates the minimal receipt into a temporary file, applies the same
normalization, and compares bytes; expected files are inputs, not collection
targets, so they live outside the scanned fixture root.
