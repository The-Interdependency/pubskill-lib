# Expected fixture collection

`collection-normalized.json` is the exact, replayable schema-2 collection for
`examples/metadata-repo`, generated by the canonical collector:

```bash
PYTHONPATH=.agents/skills python -m msdmd.collect \
  --root examples/metadata-repo --repo fixture/metadata-repo \
  --snapshot-identity --strict --json \
  --out /tmp/fixture-collection.json
```

The only normalization applied is the Python reader's runtime version label
(`"version": "Python 3.x"` becomes `"version": "Python <normalized>"`), so the
same committed file replays byte-for-byte on every supported interpreter.
The test gate regenerates the collection into a temporary file, applies the
same normalization, and compares bytes; expected files are inputs, not
collection targets, so they live outside the scanned fixture root.
